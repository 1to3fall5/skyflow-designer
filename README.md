# SkyFlow Designer

SkyFlow Designer 是一款基于 Web 的专业工具，用于创建动态天空盒流动贴图（Flowmaps）。它支持导入天空纹理、实时绘制流向矢量，并在 3D 场景中即时预览动画效果。非常适合为游戏引擎（如 Unity、Unreal、Godot 等）创建动态天空效果。

## 主要功能

- 🎨 **流动绘制**：直观的笔刷和橡皮擦工具，用于定义流动的方向 and 强度。
- 🖼️ **纹理支持**：支持导入自定义天空盒图像（等距柱状投影/全景图）。
- 🔄 **实时预览**：在球体上即时可视化流动效果，可调节速度和扭曲程度。
- 🛠️ **高级工具**：
  - 全局风向控制。
  - 支持极坐标和等距柱状投影模式，方便在两极进行精确绘制。
  - 非破坏性的全局模糊处理。
  - 可视化辅助工具（参考图叠加、箭头流向显示）。
- 📤 **导出**：生成并下载流动贴图（支持标准或反转通道）。

## 使用指南

### 1. 准备背景图
点击左侧面板的 **“更换天空贴图”** 按钮，上传您的等距柱状投影（Equirectangular）格式的天空图片。这通常是一张 2:1 比例的全景图。

### 2. 绘制流向
- **选择工具**：在左侧工具栏选择 **“画笔”** 绘制流向，或选择 **“橡皮擦”** 擦除。
- **调整参数**：设置笔刷的大小、硬度和流动强度。
- **绘制技巧**：
  - 点击并拖动鼠标以定义流动方向。
  - 使用 **“极坐标模式”** 可以在绘制天空顶部或底部（极点）时避免拉伸变形。
  - 开启 **“显示流向箭头”** 可以直观地看到当前的矢量场分布。

### 3. 实时预览
右侧的 3D 窗口会自动应用您绘制的流动贴图。
- **动画控制**：调节 “流动速度” 和 “扭曲程度” 以获得满意的动态效果。
- **视角查看**：在 3D 窗口中通过鼠标左键旋转、右键平移、滚轮缩放来观察天空盒的不同角度。

### 4. 导出结果
满意后，点击左侧底部的 **“导出 Flowmap”** 按钮。
- **格式说明**：导出的图片中，红色通道（R）代表水平方向偏移，绿色通道（G）代表垂直方向偏移。
- **通道反转**：如果您的引擎需要不同的坐标系，可以勾选 “反转通道” 后再导出。

## 快捷键说明

| 快捷键 | 功能 |
| :--- | :--- |
| **B** | 切换至 **画笔** 工具 |
| **E** | 切换至 **橡皮擦** 工具 |
| **V** | 显示/隐藏 **流向箭头** |
| **1** | 切换至 **2D 绘制视图** |
| **2** | 切换至 **分屏视图** |
| **3** | 切换至 **3D 预览视图** |
| **F** | **重置 2D 视图**（按下并松开） / **调整笔刷大小**（按下并左右拖动鼠标） |
| **Ctrl + Z** | 撤销（Undo） |
| **Ctrl + Y / Ctrl + Shift + Z** | 重做（Redo） |
| **鼠标滚轮** | 在 2D/3D 视图中缩放 |
| **鼠标右键** | 在 3D 视图中平移相机 |

## 技术栈

- **框架**：React + Vite
- **3D 引擎**：Three.js / React Three Fiber
- **样式**：TailwindCSS
- **图标**：Lucide React

## 快速开始

### 前置条件

- Node.js (推荐 v18 或更高版本)

### 安装步骤

1. 克隆仓库：
   ```bash
   git clone https://github.com/1to3fall5.git
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 启动开发服务器：
   ```bash
   npm run dev
   ```

4. 在浏览器中访问 `http://localhost:5173`。

## 部署

本项目是一个静态 Web 应用，可以轻松部署到任何静态托管服务。

### 推荐平台
- **腾讯云 EdgeOne Pages**
- **Vercel**
- **Netlify**
- **GitHub Pages**

### 构建

构建生产版本：

```bash
npm run build
```

构建后的文件将生成在 `dist` 目录中。
