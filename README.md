# SkyFlow Designer

SkyFlow Designer 是一款基于 Web 的专业工具，用于创建动态天空盒流动贴图（Flowmaps）。它支持导入天空纹理、实时绘制流向矢量，并在 3D 场景中即时预览动画效果。非常适合为游戏引擎（如 Unity、Unreal、Godot 等）创建动态天空效果。

## 主要功能

- 🎨 **流动绘制**：直观的笔刷和橡皮擦工具，用于定义流动的方向和强度。
- 🖼️ **纹理支持**：支持导入自定义天空盒图像（等距柱状投影/全景图）。
- 🔄 **实时预览**：在球体上即时可视化流动效果，可调节速度和扭曲程度。
- 🛠️ **高级工具**：
  - 全局风向控制。
  - 支持极坐标和等距柱状投影模式，方便在两极进行精确绘制。
  - 非破坏性的全局模糊处理。
  - 可视化辅助工具（参考图叠加、箭头流向显示）。
- 📤 **导出**：生成并下载流动贴图（支持标准或反转通道）。

## 使用指南

### 1. 准备背景图
在左侧侧边栏的 **“图片源”** 区域，上传您的等距柱状投影（Equirectangular）格式的天空图片。这通常是一张 2:1 比例的全景图。

### 2. 绘制流向
- **选择工具**：
  - **画笔/橡皮擦**：在屏幕底部中央的浮动工具栏中切换 **“画笔”** 和 **“橡皮擦”**。
  - **魔棒工具**：使用快捷键 `M` 或点击左上角的 **“？”** 按钮打开快捷键面板进行选择。
- **调整参数**：在底部中央的工具栏中直接拖动滑块调整笔刷的 **大小** 和 **强度**。
- **绘制技巧**：
  - 点击并拖动鼠标以定义流动方向。
  - 使用 **“极坐标模式”** 可以在绘制天空顶部或底部（极点）时避免拉伸变形。
  - 开启 **“显示箭头”**（顶部悬浮栏或快捷键 `A`）可以直观地看到当前的矢量场分布。

### 3. 实时预览
右侧的 3D 窗口会自动应用您绘制的流动贴图。
- **动画控制**：在顶部悬浮栏调节 “速度” 和 “强度” 以获得满意的动态效果。
- **视角查看**：在 3D 窗口中通过鼠标左键旋转、右键平移、滚轮缩放来观察天空盒的不同角度。

### 4. 导出结果
满意后，点击顶部导航栏右侧的 **“导出”** 按钮。
- **格式说明**：导出的图片中，红色通道（R）代表水平方向偏移，绿色通道（G）代表垂直方向偏移。
- **通道反转**：如果您的引擎需要不同的坐标系，可以勾选导出按钮旁的 “R” 或 “G” 复选框进行反转。

## 界面布局

- **顶部左侧**：**帮助/快捷键** 按钮（问号图标）。
- **底部中央**：**笔刷设置**（工具切换、大小、强度）。
- **左侧侧边栏**：图片源、图层管理、全局设置。
- **顶部悬浮栏**：预览动画控制、辅助显示开关。

## 快捷键说明

| 快捷键 | 功能 |
| :--- | :--- |
| **B** | 切换至 **画笔** 工具 |
| **E** | 切换至 **橡皮擦** 工具 |
| **M** | 切换至 **魔棒** 工具 |
| **A** | 显示/隐藏 **流向箭头** |
| **Space** | 播放/暂停 **流动动画** |
| **1** | 切换至 **2D 绘制视图** |
| **2** | 切换至 **分屏视图** |
| **3** | 切换至 **3D 预览视图** |
| **F** | **重置 2D 视图**（按下并松开） / **调整笔刷大小**（按下并左右拖动鼠标） |
| **Ctrl + F** | **调整笔刷强度**（按下并左右拖动鼠标） |
| **Ctrl + Z** | 撤销（Undo） |
| **Ctrl + Y / Ctrl + Shift + Z** | 重做（Redo） |
| **鼠标滚轮** | 在 2D/3D 视图中缩放 |
| **鼠标中键** | 平移视图 |
| **鼠标右键** | 在 3D 视图中平移相机 |
| **? / /** | 显示/隐藏快捷键面板 |

## 技术栈

- **框架**：React + Vite
- **3D 引擎**：Three.js / React Three Fiber
- **样式**：TailwindCSS
- **图标**：Lucide React

## 快速开始

### 前置条件

- Node.js (推荐 v18 或更高版本)

### 安装步骤

1. 克隆仓库：
   ```bash
   git clone https://github.com/1to3fall5.git
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 启动开发服务器：
   ```bash
   npm run dev
   ```

4. 在浏览器中访问 `http://localhost:5173`。

## 部署

本项目是一个静态 Web 应用，可以轻松部署到任何静态托管服务。

### 推荐平台
- **腾讯云 EdgeOne Pages**
- **Vercel**
- **Netlify**
- **GitHub Pages**

### 构建

构建生产版本：

```bash
npm run build
```

构建后的文件将生成在 `dist` 目录中。
